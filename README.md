# Walterhof Website Concept

High-end sales/demo concept for Pflegeheim Walterhof GmbH, Markt Schwaben.

## Pages
- `index.html` — public website
- `preise.html` — transparent current pricing
- `karriere.html` — recruiting experience
- `admin.html` — demo admin cockpit (sample data only)
