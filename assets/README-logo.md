# Walterhof Logo Assets

- `walterhof-mark.svg` – skalierbare Bildmarke, transparenter Hintergrund
- `walterhof-logo-light.svg` – vollständiger Logo-Lockup für helle Hintergründe
- `walterhof-logo-dark.svg` – vollständiger Logo-Lockup für dunkle Hintergründe
- `/favicon.svg` – skalierbares Browser-/App-Icon

Die Website nutzt die Bildmarke im Header und Footer über die bestehenden Brand-Komponenten.
